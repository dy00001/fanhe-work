### 1.9 千牛直采取证（只读侦察 + 文档，**未提交**）

产出 `docs/ops/QIANNIU-CAPTURE-2026-10-21.md`（16.8KB，10 节 + GitHub 参考）。

**环境事实**：千牛 `9.97.86N`，Qt 壳 + CEF 130.1（不是 Electron）。当前 6 个 CEF 实例 / 3 个账号。CEF browser 进程是 `AliRender.exe`，`--cef_dir=instance_N` 区分实例，`--crash_dump_uid` 才是账号标识（**实例编号每次启动都变，不能当稳定键**）。

**三条口子全部实测堵死**：

| 通道 | 实测结论 |
| --- | --- |
| CEF 调试端口 | `setting.json` 的 `debug.*.enable/framework:9224/app:9225` 是**小程序（Windmill）**端口；本机小程序 appId 只有 `2134`、`10000990`，sycm 不在其中。CEF 启动参数无 `--remote-debugging-port` |
| 磁盘 cookie | 7 个实例的 `Cookies` 库**全是 20480 字节空表**，淘系域名 0 条。登录态在 `AuthSDK\CGX`（3820B 加密 token）+ 内存 cookie manager，不落盘 |
| 自带代理 | `System\proxy.xml` 只有 `UICServiceWin::SetProxy` / `DoLoginProxy` 读它，**网页浏览流量不走**。type=0/type=1 各试一次，代理 0 连接。实验已完整回滚（proxy.xml 恢复原 210 字节、测试窗口与 CEF 子进程全关、原 6 实例 3 账号未受影响） |

**重要更正（上午的结论是错的）**：生意参谋**确实在千牛窗口内加载**。证据在 `D:\AliWorkbenchData\System\log\app.log`：`PageContainerPresenter.cpp(304) OnNewWindow url=https://sycm.taobao.com/portal/home.htm`、`OnLoadEnd httpStatusCode=200`；渲染器是 `WebControl.cpp`（CEF webview），不是小程序。教训：**资源文件里搜不到 ≠ 运行时不会加载，要查日志。**

**剩下的路**：① 系统代理（PAC 只劫持 `*.taobao.com`/`*.tmall.com`/`*.alicdn.com`）+ 本地根 CA + TLS 终止 —— 能拿原始 mtop JSON，侵入性最大；② UI 自动化读已渲染界面（KPI 文本可读，ECharts canvas 读不到，CEF 可访问性树是否对 UIA 开放**未验证**）；③ **维持 Edge 每店 profile + CDP（推荐）**。

GitHub 参考：`rakei076/sycm-cli`(★73)、`sishenhei7/chrome-plugin-sycm`(★22)、`automation9417/qianniu`(★76)、`wantoper/QianNiuClient_Dll`(★9，**DLL 注入不要用**)。前两个反证了通用解法是「从已登录的浏览器取数」而非「从客户端取数」。

| 7897 | 本机代理（**不一定在跑**，且端口每次会话可能变） |

**本地端口请求一律加 `--noproxy '*'`**，否则被送进代理，返回 HTTP 000 / `upstream connect failed`，看起来像服务没起来。

### 4.3 容器

操作**一律经 `infra/portable/ws-compose.cmd`**（手写 `--env-file` 会被忘掉 → 报 `required variable ... is missing`，读起来像 bug）。

| 容器 | 作用 | 何时需要 `--build` |
| --- | --- | --- |
| `db` | Postgres 16 | 否 |
| `migrate` | 跑迁移 + 种子 | **改了迁移 SQL 或权限点时必须** |
| `api` | Fastify | **改了权限点常量、路由、ops 逻辑时必须** |
| `web` | 静态前端 | 前端改动是构建产物 → `build web` + `--force-recreate` |
| `cloudflared` | 隧道 | 否 |

### 4.4 采集端

- 配置：`tools/collector/shops.config.json`（**不含凭据**，`code` 必须与库中 `ecom_shops.code` 一致）
- profile：`tools/collector/.browser-profile/<code>`（**DPAPI 加密绑定本机账户，换机必失效，已 gitignore**）
- 产物：`tools/collector/data/daily/<code>/<date>`（已 gitignore）
- 密钥目录：`tools/collector/.secrets/`（**明文 cookie 等同密码，已 gitignore，用完即删**）

### 4.5 凭据

- 仓库 PAT 经 GCM 存在 `~/.gitconfig`（逐机逐用户，**换机必须重配**）
- `.tmp/owner-credentials.txt` 的口令**可能已被 `db:reset-password` 改掉** → **不要猜口令**（会累计失败并锁定）、**不要代跑重置**，要自动化登录先问人

### 5.3 换机注意事项（逐条坑）

| 坑 | 表现 | 处理 |
| --- | --- | --- |
| `.gitconfig` 有 **URL 级** `http.https://github.com/.proxy` | 代理没起来时 git 全挂（`over proxy 127.0.0.1`），而 `curl` 同址正常 | 绕过：`-c "http.https://github.com/.proxy="`（**整段加引号**） |
| GCM 在等交互 | 卡在 0 字节日志数分钟 | 判据：`git ls-remote origin HEAD` 秒回即正常；否则重配凭据 |
| `push origin dev` 在 dev 落后 main 时必被拒 | — | 先 `git branch -f dev main` 再一起推 |
| 推内联 URL 不更新 `refs/remotes/origin/*` | `branch -vv` 看着没推上去 | **验收以 `ls-remote` 为准** |
| 安全删除守卫 | `pnpm install` 报 `ERR_PNPM_ABORTED_REMOVE_MODULES_DIR_NO_TTY` / 删目录被挡 | 加 `CI=true --config.confirmModulesPurge=false`；删目录加 `CODEBUDDY_SAFE_DELETE_BULK_THRESHOLD=<大数>` |
| `prisma generate` 被中断 | `apps/api/src/generated/` 写成半截 → 12 个文件报 `does not provide an export named 'PrismaClient'` | 看着像代码坏了。门禁**一次只跑一轮**，别并行 |
| `cmd //c ... \| tail` 后 `echo $?` | 是 `tail` 的退出码 | 循环跑门禁会把失败当全绿。判据用命令自身退出码或输出里的 `ELIFECYCLE` |
| PowerShell 5.1 编码 | 中文日志乱码、`.ps1` 报语法错 | `.ps1` 必须纯 ASCII 或带 BOM；脚本开头设 `[Console]::OutputEncoding` |
| `.mjs` 里写 TS 类型标注 | `SyntaxError: Unexpected token ':'`，**报错行号指向 import 处** | `--experimental-strip-types` 只管 `.ts` |
| 起服务前不查端口 | 遗留 `tsx watch` 占 8787 → 新进程 EADDRINUSE **静默退出**，浏览器看到的仍是旧进程 | 先 `netstat` 查监听者 |
| 桌面端打包态冒烟 | GPU 进程 `0xC0000005` → `ERR_FAILED (-2)` | 先 `env -u NODE_OPTIONS -u ELECTRON_RUN_AS_NODE`，再加 `--no-sandbox --disable-gpu-sandbox --use-angle=swiftshader`；真实桌面会话仍要默认参数复跑 |
| 跑完 test 清残留 | 残留账号命名 `zz_test_*` | **见 `users=2` / 有 `notes` 行先确认是不是用户自己的数据**（曾差点把阿阳刚建的子账号当残留清掉） |
