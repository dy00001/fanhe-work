企业级中后台

Ant Design 5 配 Pro 布局骨架

浅色侧栏，蓝色主色，圆角 8px。组件覆盖最全，中文文档最完善，权限与路由骨架现成。开发速度最快。

中性灰阶，产品感优先

C

桌面原生

Fluent 设计语言，Windows 11 观感

Segoe UI 字体族，圆角 4px，双层描边与浅投影，选中项带左侧强调条。桌面端原生感最强，中文资料相对少。

D

深色导航高密度

经典企业形态，信息密度最高

深色侧栏配白色内容区，顶栏压缩到 50px，行高收紧，增加指标卡带与操作人列。同屏可见条目最多。
