### 2.5 阶段四 T4-01 Electron 外壳脚手架（本轮完成）

`apps/desktop` 从空目录落成一个能用的外壳。

| 项 | 交付 |
| --- | --- |
| 工程落点 | `apps/desktop/{package.json,tsconfig.json}`、`src/{main,preload,server}.ts`、`scripts/{ensure-electron,launch}.mjs`、`test/server.test.mjs` |
| 承载方式 | 主进程在回环上起**内置静态服务**托管 `apps/web/dist`，并把 `/api/*` **反代**到服务地址（含 SPA 回退）。**`apps/web` 一行未改**，单一来源前提继续成立 |
| 模块格式 | **刻意用 CommonJS**（`package.json` 不写 `"type": "module"`），保住沙箱化的预加载脚本 |
| 二进制 | Electron 44.7.0 **无 `scripts.postinstall`**，补 `ensure-electron.mjs` 并由根 `postinstall` 调用（幂等） |
| 启动器 | 摘掉 `ELECTRON_RUN_AS_NODE`；按 `FANHE_NO_SANDBOX` 决定是否关沙箱；渲染进程 `no-proxy-server` |

**为什么不用 `file://`**：`file://` 页面来源是 `null`，向 API 发 `fetch` 会被跨域拦（服务端从不发 CORS），且 `BrowserRouter` 深链直接失败 —— 加 `base` 解决不了。判断详见 `DEVELOPMENT-PLAN.md` 9.41。
